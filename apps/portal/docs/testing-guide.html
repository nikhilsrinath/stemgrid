How it works

Real

Every page, button, form, rule and limit. Sign-ins, sessions, permissions, the database security, PINs, batches, billing calculations, invoices, the simulator.

Fake (only on your laptop)

Payments: a "Test payment" page with Pay / Fail / Cancel.
Emails: shown in a Mailbox page.
Enquiries: 5 samples instead of the live form.
Date: you can pretend it's another day.

Separate

The database runs in Docker on your laptop. It never connects to the live portal, the live simulator database, Razorpay or Resend. Reset it whenever you like.

Two addresses, just like production:

learn.localhost:3002= learn.stemgrid.in (institutes, teachers, students)
admin.localhost:3002= admin.stemgrid.in (StemGrid team console)

Always use these two addresses, not plain localhost:3002. They keep sign-ins separate, the same way the live sites will.

Start the portal

  2. pnpm install
  3. pnpm portal:local
    The first run downloads the database (several minutes). When the terminal prints the box of links and logins, it's ready. Leave the terminal open. Press Ctrl + C to stop.

To start over from fresh demo data at any time: pnpm portal:reset, or the Reset demo data button on the toolbar.

Test scripts

Do them in order the first time. Green text says what you should see. If you see something else, note the step number and send it to the developer.

If something goes wrong

"Start Docker Desktop, then run this again."Open Docker Desktop and wait for "Engine running". If it stays on "starting", restart the computer.
A page says "Page not found"Check you used learn.localhost:3002 or admin.localhost:3002, not plain localhost.
"Couldn't sign in as …" from Switch userPress Reset demo data (or run pnpm portal:reset).
Things look odd after changing the dateGo to Date → Back to today's real date, or reset the demo.
Port 3002 is busyAnother copy is running. Close the other terminal, or restart the computer.
Stop everythingCtrl + C in the terminal. To also stop the database: cd apps/portal then supabase stop.
