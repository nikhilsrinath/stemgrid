## 1. Who we are

## 3. How Lab on Wheels works (a StemGrid week)

1. **Tutor arrives.** A trained StemGrid tutor walks in with a full class set of charged, ready-to-go kits.
2. **Learn the idea.** A short, visual lesson on the week's concept: sensors, motors, logic or code.
3. **Build it.** Students snap modules onto the Quark grid. No breadboards, no soldering, no mess.
4. **Code it.** Drag-and-drop blocks or MicroPython in NerdEditor, uploaded to the board in one click.
5. **Show, track, pack up.** Students demo their builds, progress is logged, and the kits leave with the tutor.

*Same day. Same tutor. New build.*

## 7. Product: Qbitio X1 (electronics learning console)

**Tagline:** *Learn · Build · Explore.* Plug in. Code. Build anything.

X1 combines a colour display, physical controls, a plug-and-play sensor interface and an open GPIO expander in one compact, battery-powered board. A first-time learner or an experienced maker can build working projects without soldering, breadboards or complex setup. It ships with built-in projects that run as soon as a sensor module is plugged in. Students then code their own projects in the Qbitio companion app.

**Who it's for:** first-time electronics and programming students; teachers and institutions running STEM labs; hobbyists and makers; self-learners.

### 7.1 Technical specifications
| Category | Specification |
|---|---|
| Display | 1.9", 170 × 320 px colour |
| Sensor ports | 4 × 4-pin, 1 × 6-pin (auto-detected) |
| Expansion | 16-pin GPIO expander |
| Buttons | 4 navigation, 1 Select, 1 Exit, 1 Power |
| Indicator | 1 × NeoPixel (RGB) LED |
| Haptics | 1 × vibration motor |
| Audio | Built-in speaker |
| Wireless | Bluetooth, Wi-Fi |
| Wired | USB |
| Storage | SD card slot |
| Battery | 1000 mAh, fast charging |
| Power management | Battery saver mode |
| Software | Qbitio companion app (code, connect, run) + built-in projects |

**In the box:** 1 × X1 board, 1 × USB cable, 1 × quick start card. *Sensor modules are sold separately or in learning kits.*

### 7.2 Controls
| Control | Qty | Function |
|---|---|---|
| Navigation | 4 | Move through menus, lists, project screens |
| Select | 1 | Confirm, open a project, start or stop a run |
| Exit | 1 | Go back one level, or leave the running project |
| Power | 1 | Turn on and off |

### 7.3 Getting started
**From first plug to first program:** Plug in a sensor → Pick a project → Press Select → Learn & modify → Code in the app.

- **First power-on:**
  1. Charge X1 fully.
  2. Hold Power until the display lights up.
  3. Use the navigation buttons to move through the menu, and press Select to open an item.
  4. Press Exit to go back.
- **Run a built-in project:**
  1. Plug in the sensor the project needs.
  2. Open Projects.
  3. Highlight a project and press Select.
  4. Watch the output. Press Exit to stop.
  No coding is needed.
- **Use the Qbitio app:**
  1. Install the app.
  2. Connect over USB, Bluetooth or Wi-Fi.
  3. Select the board.
  4. Write or open a project and press Run.

### 7.4 Power, connectivity & storage
- 1000 mAh rechargeable battery with fast USB charging. X1 can be used while charging.
- Battery saver mode is in device settings.
- **USB:** charging, connecting to the app, uploads and firmware updates.
- **Bluetooth:** wireless connection to the app and nearby devices.
- **Wi-Fi:** connected projects and wireless connection to the app.
- **SD card:** project files, logs, images and sounds. Insert or remove the card only with the power off.

### 7.5 Expansion
- Add third-party sensors, actuators and displays through the 16-pin GPIO expander.
- Combine plug-and-play modules and GPIO modules in one project.
- Store collected data on the SD card.

### 7.6 Safety & care
- Keep away from water.
- Don't short the GPIO or port pins.
- Check module voltage and current ratings before connecting.
- Disconnect power before changing GPIO wiring.
- Don't use damaged cables.
- Adult supervision is recommended for younger learners.
- Dispose of the product and battery according to local e-waste rules.

### 7.7 FAQ
- **Need to code?** No. Built-in projects work with plug-and-play sensors, and coding is optional.
- **Need soldering?** No.
- **Use while charging?** Yes.
- **Connect my own components?** Yes, through the GPIO expander.
- **How do I update it?** Connect to the Qbitio app over USB and follow the prompt.

*(Source: Qbitio X1 Product Documentation v1.0, November 2026. Specifications may change.)*
